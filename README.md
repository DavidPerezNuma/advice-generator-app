# Advice generator app

Solución del reto [Advice generator app](https://www.frontendmentor.io/challenges/advice-generator-app-QdUG-13db) de Frontend Mentor.

Actividad 4 – Herramientas de Software I. Aplicación web en HTML, CSS y JavaScript que consulta la API pública [Advice Slip](https://api.adviceslip.com/).

## Funcionalidades
- Muestra un consejo aleatorio al cargar la página.
- El botón del dado consulta un consejo nuevo a la API.
- Estado de carga y mensaje de error si la API no responde.
- Diseño responsive (móvil 375 px y escritorio 1440 px).

## Tecnologías
HTML5, CSS3 (variables, Flexbox, media queries) y JavaScript (Fetch API, async/await).

## Ejecutar localmente
Abrir `index.html` en el navegador (requiere conexión a internet).
